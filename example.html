PowerAsia R&D Mechanical Engineer Intern

Current-Based Motor Belt Fault Detection System

Extended an AI-powered motor monitoring system to detect mechanical faults such as belt failures. Designed and implemented a current trend–based algorithm for belt fault detection and integrated it into the existing AI monitoring system.

  • Current trend–based belt fault detection algorithm
  • Signal processing & threshold-based fault classification
  • Differentiated belt slippage, breakage, VFD speed changes, and normal fluctuations
  • Implemented and validated using C++ (Arduino)
  • Data acquisition, parameter tuning, and system debugging

Three-phase current trends of an AC motor driven by a VFD, used to distinguish normal operation from belt faults.

Pump System Design

Designed a pump and piping system to deliver water from a well to a tank, satisfying flow rate, pressure, and cost constraints. Evaluated multiple design alternatives and selected the most economical solution over a 10-year cost horizon.

  • Head loss and system curve calculation
  • Pump curve analysis and operating point determination
  • Pump power, energy use, and cost estimation
  • Pipe pressure safety verification
  • Studied effects of pump speed and impeller size

Recommended design: 3600 rpm pump, 3.25″ impeller, 2.5″ Schedule 80 PVC pipe — balancing operating pressure, flow rate, and cost efficiency.

Pump and system curve used to determine the optimal operating point.

Thermal Design

AHU Load Calculation & Design Optimization

Evaluated an air handling unit (AHU) system at the Rexburg Temple, comparing the existing steam humidifier design against a proposed pressurized humidifier through thermal load and energy cost analysis.

  • Psychrometric analysis and air property evaluation
  • Heating and cooling load calculations
  • Energy consumption and operational cost estimation
  • Humidification system & HVAC performance evaluation

Recommended replacing the steam humidifier with a pressurized humidifier to improve efficiency and reduce cost.

Numerical Methods

Root-Finding Algorithm Comparison

Compared the Bisection, Secant, and Ridder's methods for root finding on a continuous function, analyzing convergence rate and relative error at each iteration.

  • Implemented Bisection, Secant, and Ridder's methods
  • Convergence and relative error analysis
  • Numerical result visualization

All three methods converge to the same root (x ≈ 0.948); Secant and Ridder's methods reach near machine-zero error faster than Bisection.

Mechatronic System I

Arduino Sous Vide Controller

Designed and built an Arduino-based sous-vide cooking controller that maintains a user-defined water temperature via closed-loop PID control, with sensor acquisition, relay-based actuation, and an LCD + joystick interface.

  • Closed-loop PID control & Time Proportional Output
  • Real-time feedback with DS18B20 sensor
  • C/C++ programming on Arduino Uno
  • 16x2 I2C LCD & joystick user interface

Achieved temperature stability within ±0.5°C.
